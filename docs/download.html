Get the Daybook app

Daybook for Android. It works offline and keeps the same private pages you write on the web.

Download for Android (.apk)

Signed release build. Android only. Requires Android 8 or newer.

Installing

  • Open the downloaded file. If Android asks, allow installs from your browser (Settings, Install unknown apps).
  • Android may say the app is not from the Play Store. That is expected for a file installed directly.
  • Sign in with the same Google account and your entries appear.

Already installed an older copy?

Older test copies were signed with a different key, so Android cannot update them in place. Make sure your entries have synced (they do whenever you are online), uninstall the old one, then install this one and sign in again.

Get updates automatically

Install Obtainium (a free app that installs and updates apps straight from their release page), then add this address: https://github.com/geosubash-glitch/daybook. It will tell you when a new version is out and update Daybook for you.

No install needed

Daybook also runs in your browser at the same address. On a phone, use your browser's menu and choose Add to Home screen to get an app-style icon.
